# Historical plans and milestone records

> **Document status:** Historical
> **Code authority:** none; current code, tests, migrations and `docs/architecture.md`
> **Last verified:** 2026-09-05

Files in this directory preserve roadmap decisions, proof-of-concept notes, task
breakdowns, and milestone sign-off context. They are not current implementation
instructions.

Names, paths, interfaces, migration numbers, performance figures, and unchecked
tasks may reflect the repository at the time the plan was written. Before using
any detail:

1. Confirm the current behavior in code and tests.
2. Use `docs/README.md` to find the current component reference.
3. Treat unchecked work as unshipped unless current code proves otherwise.
4. Create a new Proposed document or ADR for future work instead of editing
   history to look current.

Historical plans should only receive typo/link/status annotations. Materially new
design belongs outside this directory until it is complete, then the implementation
should be documented in the owning Reference/Canonical document.
